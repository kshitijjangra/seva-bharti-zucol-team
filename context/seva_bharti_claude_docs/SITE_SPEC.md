# Site Specification

## Approved routes

| Page | Suggested route | Purpose |
|---|---|---|
| Home | `/` | Main landing page |
| About Us | `/about-us` | Official organizational information |
| Shiksha | `/shiksha` | First pillar |
| Swavalamban | `/swavalamban` | Second pillar |
| Samajik | `/samajik` | Third pillar |
| Swasthya | `/swasthya` | Fourth pillar |
| Events | `/events` | Supplied event information and photos |
| Contact | `/contact` | Supplied contact information |

Pillar spellings and labels must be checked against official material
before publication. The names above follow the available audio transcript.

## Shared layout
- Consistent header and navigation.
- Supplied Seva Bharti logo.
- Clear page headings and readable content.
- Footer containing only approved information.
- Responsive navigation and layout.
- Links only to the eight approved pages.

## Home
Use supplied content only. A visual entry point to the four pillars is
permitted because the four pillars are explicitly requested. Do not
invent a slogan, impact metric, testimonial, or organizational claim.

## About Us
Use approved organizational description, history, and other details
only when the user supplies them.

## Four pillar pages
Each page may contain:
- Official title.
- User-provided description.
- User-provided photographs.
- User-provided success stories, if any.

Do not invent a standard set of sections when there is no content for them.
Omit unsupported sections or mark them as content required.

## Events
Create a simple gallery/list from the supplied photographs and event data.
No fabricated events, captions, dates, or locations.
No admin editing or CMS.

## Contact
Render only contact information supplied by the user.
Do not guess a location, phone number, email, or social profile.

## Static behaviour
Prefer build-time rendering and local data. The Events page may display
different supplied entries from local data files, but this does not mean
there is a live publishing system.

## Excluded
- Additional pages.
- Blog or news page.
- Donation or payment system.
- Admin dashboard or CMS.
- User accounts or login.
- Invented content.
- Unapproved integrations.
