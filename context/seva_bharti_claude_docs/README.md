# Seva Bharti Website — Claude Documentation

This package defines the scope and implementation constraints for the
Seva Bharti Next.js website.

## Included documentation
- `CLAUDE.md`: master project instructions
- `SITE_SPEC.md`: eight approved pages and behaviour
- `DESIGN_SYSTEM.md`: logo-led visual direction
- `CONTENT_SCHEMA.md`: content and asset rules
- `CLAUDE_BUILD_PROMPT.md`: implementation prompt

## Approved pages
Home, About Us, Shiksha, Swavalamban, Samajik, Swasthya, Events, Contact.

## Important
This is a statically generated website specification, not a request for
a CMS or admin dashboard. Use only information supplied by the user.

The four pillar names are based on audio transcription and should be
verified against official source material.

## How to use
1. Extract this package.
2. Open the website project in Claude Code or your chosen Claude coding
   workflow.
3. Copy these Markdown files into the project root.
4. Put the original logo in the project's public assets folder.
5. Supply the approved text and photographs.
6. Send the contents of `CLAUDE_BUILD_PROMPT.md` to Claude.
7. Review the generated site and replace all editorial placeholders
   before publication.
